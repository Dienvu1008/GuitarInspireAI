# ADR-026 Bundled SoundFont: a trimmed FluidR3 GM (guitar preset only)
Status: Accepted (user, 2026-10-31, Phase 4 slice 4c decision A)
Date: 2026-10-31
Related documents: [ADR-015](ADR-015-dependency-license-policy.md), [ADR-010](ADR-010-local-first.md), [ADR-024](ADR-024-playback-rendering-conventions-and-rt-failures.md), [audio-dsp-architecture.md](../audio-dsp-architecture.md), [fitness-functions.md](../fitness-functions.md)

## Context
Playback (ADR-024) uses one General MIDI program, 25 (Acoustic Guitar (steel)). The default SoundFont is FluidR3 GM (ADR-015, 2026-10-31). The full `FluidR3_GM.sf2` is 148.4 MB (131.8 MB zipped). Bundling it would multiply the Windows app bundle (30.9 MB release, 13.1 MB zipped) about elevenfold, and git/GitHub reject files over 100 MB. The MIT license of FluidR3 permits derivative works, so the SoundFont can be reduced to the guitar preset.

## Decision
1. Bundle a trimmed SoundFont, `GuitarSteel.sf2`, containing only bank 0 program 25 ("Steel String Guitar") of FluidR3 GM, with the instruments and samples that preset references. Measured: 2 108 670 bytes (1.8 MB zipped), well under the ~50 MB zipped release threshold. It loads in rustysynth 1.3.8 and renders audio for program 25.
2. The trim is reproducible from the repository: `tools/sf2-trim/trim_sf2.py` (standard library only) selects presets by bank and program and rebuilds every pdta sub-chunk with a compacted sample pool. No hand-edited "one-off" file is accepted; the file is regenerated by running the script on the recorded source archive. `tools/sf2-trim/probe.py` lists the presets of any SF2 for verification.
3. Provenance is recorded in `assets/soundfonts/PROVENANCE.md`: the source archive and its SHA-256, the extracted source SoundFont and its SHA-256, the exact trim command, the list of kept presets, the trimmed file and its SHA-256, and the MIT permission for derivatives.
4. The original MIT `COPYING` text travels with the file (`assets/soundfonts/FluidR3-COPYING.txt`) and goes into the release third-party notices (ADR-015). The trimmed file is a derivative under the same MIT license; the notices say so.
5. No network fetch at runtime (ADR-010): the trimmed file is committed and bundled. The full SoundFont is not committed. If a future need for more instruments appears, options are to add their presets to the trim list (re-measuring size) or, only if the result is too large, fall back to a build-time download of a pinned, hash-checked file (ADR-010 would need an amendment). Loading stays lazy at the first Play (slice 4c); a missing or invalid file disables playback with a message and no sine fallback.

## Alternatives
- Bundle the full FluidR3 GM: 131.8 MB zipped, over the GitHub 100 MB file limit; rejected (option B kept only as a fallback if a trim ever exceeds the threshold).
- Download at first run (option C): conflicts with ADR-010 (local-first, no network in MVP); rejected.
- A different small GM SoundFont: FluidR3 is already the chosen default (ADR-015) and its license is confirmed from the original COPYING.

## Trade-offs
One preset means only the steel-string guitar sound in the MVP, which matches ADR-024 (fixed program 25). Adding instruments later re-runs the trim and re-measures the bundle (FF-29). The trim script is project-specific code to maintain.

## Consequences
`assets/soundfonts/` holds `GuitarSteel.sf2`, `FluidR3-COPYING.txt` and `PROVENANCE.md`. `tools/sf2-trim/` holds the reproducible scripts. FF-29 (bundle size) counts the trimmed file. `cargo deny` is unaffected (SF2 is data, not a crate). ADR-015's SoundFont conditions are satisfied by the provenance record and the bundled license text.

## Related fitness functions
FF-09 (license policy, data provenance), FF-29 (bundle size).

## Reconsideration conditions
More instruments are needed (re-trim and re-measure); the trimmed bundle ever exceeds the release threshold (then option B with a pinned download); the project gains user-supplied SoundFonts.

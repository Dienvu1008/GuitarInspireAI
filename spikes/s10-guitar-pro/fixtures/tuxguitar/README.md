# S10 fixtures written by TuxGuitar 2.0.1

Purpose: Small Guitar Pro 3, 4 and 5 files, one feature group each, to develop and check our own reader and writer (spike S10, Phase 6d).
License: CC0-1.0. The files contain no third-party music; they were generated for this project on 2026-11-11.

## Provenance

- Generated by `../../generator/MakeFixtures.java` with the user's consent (2026-11-11), because the user has TuxGuitar but no Guitar Pro.
- The program builds each song with the TuxGuitar 2.0.1 song model and writes it with **TuxGuitar's own** `GP5OutputStream`, `GP4OutputStream` and `GP3OutputStream`, with default settings. So the bytes come from TuxGuitar's writers, independently of our reader.
- Only the public API signatures of the TuxGuitar jars were used (`javap -public`); no TuxGuitar source was read.
- Each file was read back with TuxGuitar's own readers: all 42 files load, with the expected number of tracks, bars and notes.
- Two runs give byte-identical files (the generator is deterministic).

To regenerate (JDK 21, TuxGuitar 2.0.1 installed in `C:\Program Files\tuxguitar`):

```powershell
$tg = 'C:\Program Files\tuxguitar'
$cp = "$tg\lib\tuxguitar-lib.jar;$tg\lib\tuxguitar-gm-utils.jar;$tg\share\plugins\tuxguitar-gtp.jar"
javac -encoding UTF-8 -cp $cp -d $env:TEMP\s10-gen ..\..\generator\MakeFixtures.java
java -cp "$cp;$env:TEMP\s10-gen" MakeFixtures .
```

## What these files are not

- They were written by TuxGuitar, not by Guitar Pro. Guitar Pro's own files may differ (padding values, optional sections, text encoding).
- TuxGuitar writes GP5 as version `v5.00`, never `v5.10`; sections added in 5.10 are not covered.
- TuxGuitar writes text in **UTF-8** by default. The format describes 8-bit strings; Guitar Pro itself is believed to use a Windows code page [To verify with a Guitar Pro file].
- They were made through the API, not by hand in the TuxGuitar window, so defaults set only by the user interface are absent.

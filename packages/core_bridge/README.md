# core_bridge

Dart facade over the Rust Music Core (interop-architecture sections 2, 6 and 12).

- `lib/core_bridge.dart`: public API for feature packages: `DocumentService`,
  `DocumentFactory`, `CoreBridge.init()` and the DTO types. Features import only this
  file (FF-05).
- `lib/testing.dart`: `FakeDocumentService` and `FakeDocumentFactory` for widget tests.
- `lib/src/generated/`: generated by `flutter_rust_bridge_codegen generate` (pinned
  2.13.0) from `crates/mc-ffi/src/api`. Never edit by hand; FF-12 regenerates and diffs.

Regenerate after changing the Rust API:

```text
cd packages/core_bridge
flutter_rust_bridge_codegen generate
```

Tests: `flutter test` runs the shared contract (`test/contract/`) against the fake and
against the real core. The real run loads `target/debug/mc_ffi.dll`, so build it first
with `cargo build -p mc-ffi`.
